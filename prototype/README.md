# Interactive Prototype

`whitegoose-prototype.html` is a self-contained, working front-end prototype of the
storefront + admin dashboard — real cart/checkout flow, live order sync, editable
brands/products/photos from the admin panel. It's meant for client review and UX
reference, not as production code (see the root README for the real build).

Open it directly in a browser, or view the live hosted version Claude published:
https://claude.ai/artifact/97ZivqEVK6Qmd7HWXsDC9r

Note: the live-sync features (real-time orders, photo upload, editable brand/product
fields) only work when opened through the hosted Claude artifact link above — they
depend on that platform's storage APIs and won't function when the file is just
opened locally or served from GitHub Pages.
